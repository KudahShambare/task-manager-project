This document records the accessibility verification evidence for the Task Management SaaS frontend. The frontend was checked against WCAG 2.1 AA expectations using semantic HTML, labelled form controls, keyboard-accessible buttons, visible focus states, sufficient contrast, and responsive layout.

Accessibility Checks Covered

  • Semantic page structure using main, header, section, and form elements.
  • Form inputs are connected to visible label elements.
  • Status and error messages use accessible live regions with role="status" and role="alert".
  • Interactive controls are real buttons, inputs, and selects for keyboard support.
  • Text and controls use high contrast colours from the existing login form palette.
  • Responsive layout uses CSS Grid and Flexbox so the interface works on desktop and mobile screens.
